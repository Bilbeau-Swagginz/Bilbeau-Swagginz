## 🎯 What I'm working toward

Transitioning from security operations into application security and security engineering: learning how to write code and apply secure coding practices. My long-term goal is a mix of building, problem solving, and figuring out how best to defend real systems.

## 🔨 What I'm building

**[advisory-tracker](https://github.com/Bilbeau-Swagginz/advisory-tracker)**: a patch and security advisory tracker for CachyOS Linux.
- Pulls Arch Linux security advisories and checks them against installed packages
- Tailored to CachyOS, including AUR packages
- Reports which packages are vulnerable and need updates
- Planned: weekly runs and fast alerts for critical CVEs

*Status: early development, my first real project.*
